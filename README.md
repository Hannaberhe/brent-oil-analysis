# Brent Oil Price Change Point Analysis

Analyzing how geopolitical events affect Brent oil prices using Bayesian change point detection.

## Setup
pip install -r requirements.txt

## Data
- Brent oil prices (1987-2022)
- 15 major events in data/events.csv

## Tasks
1. EDA and event documentation
2. Bayesian change point modeling with PyMC
3. Flask + React dashboard
